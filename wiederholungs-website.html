Was ist HTML?

HTML steht für HyperText Markup Language. HTML bestimmt den Aufbau und den Inhalt einer Website.

Wichtige HTML-Tags

  • <h1> Überschrift
  • <p> Textabsatz
  • <a> Link
  • <img> Bild
  • <ul> Liste
  • <table> Tabelle

Was ist CSS?

CSS steht für Cascading Style Sheets. Mit CSS wird das Aussehen einer Website verändert.

Was kann CSS?

  • Farben verändern
  • Schriftarten ändern
  • Größen festlegen
  • Abstände einstellen
  • Hintergründe gestalten
  • Elemente positionieren

CSS-Syntax

p {
    color: blue;
    font-size: 20px;
}
